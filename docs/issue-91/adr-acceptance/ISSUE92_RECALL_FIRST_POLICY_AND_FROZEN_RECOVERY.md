## Corrected decision rule

**Automatically eligible:** a potentially useful atomic fact discovered as an authentic, bounded, exact original-source excerpt and positively classified for development utility through the independent first-stage review. It retains native source reference, group, project, workspace, evidence class, temporal uncertainty and positive remote identity. Within the existing finite-batch cap, it is eligible for Graphiti persistence unless an **actual hard authority, privacy, source-validity, CAS, exact duplicate, resource or EX** rule prevents it.

**Advisory, not a veto:** model judgments of semantic equivalence, novelty, representative quality, generic similarity, source-quote length used only for comparison, or a failed JSON presentation format from an optional semantic-review stage. They may inform retrieval ranking, operator cleanup and later curation, but cannot eliminate a valid, independently utility-approved fact by default. Semantic uncertainty is not proof of low utility. A few additional duplicated or borderline useful episodes are preferable to losing actionable technical constraints.

**Production path unchanged:** installed one-pass curator, normal capture, original deterministic validators, ReviewStore CAS, graph UUID/source index, Graphiti unknown-submission no replay and canonical post-exit EX all remain unchanged. The existing `--finite-batch on` is a development opt-in. It now defaults to `--novelty-policy recall`. For historical comparisons only, `--novelty-policy conservative` retains the older project-level/specificity model-suppression behavior; this restrictive mode is not the new rollout target.

**Honest limitation:** this correction eliminates novelty-induced false negatives, not the separate earlier losses from discovery choosing the wrong passage or the first-stage utility reviewer labeling concrete Graphiti constraints `not_substantive`. Those need a bounded **source-first, recall-sensitive** follow-up, not another novelty veto, before prospective acceptance. It also deliberately permits more semantic duplicates than B2; report them rather than concealing them or claiming precision.
