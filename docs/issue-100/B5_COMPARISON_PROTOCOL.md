# Issue #100 B5 comparison protocol — frozen before model inference

## Measurement authority

- **Primary**: original authenticated native source, scope, evidence class, timestamp and immutable Graphiti proof. **Model**: ordinary future-development utility/retention choice, never source authenticity or factual truth.
- Compare the actual installed **plain drain** predecessor and the candidate one-pass `--autonomous-curation on`, followed by selective new-evidence consolidation, on the **same** eligible source cases under equivalent local model settings. The old 205 deferred ReviewStore rows and 4,002 archived source events are separate populations and must not be retroactively relabeled.
- Do not use prior exposed #92 cohort as an untouched prospective test. Record it separately as a disclosed comparison set. A prospective set must be frozen by canonical source-hash/expected category and generation timestamp **before** candidate/predessor model outcomes. If truly independent developer-origin source cases are not available safely, label cohort `new_synthetic_prospective`, not external independent real-world validation.
- At least 12 relevant candidate cases when practical, including: independent multi-fact source; safe but uncertain utility; explicit user-stated unresolved defect; tool-reported negative; assistant-reported hypothesis; changing temporal standing; exact duplicate; near-duplicate with independent attribution; wrong group/source; invalid quote offset; private credential-pattern source; model malformed/no-output. Include later independent source with new terminal UUID to trigger consolidation, and identical replay to prove no repeated consideration.
- Adjudicate at **per-fact** grain: original evidence identity/quote, whether assertion was supported as reported, utility relevance for future development, evidence class, expected established/provisional/skip/technical/integrity outcome, model result, current source/Graphiti terminal UUID, and cost. An exact quote can be supportable without the event's author being factually correct.
- The reviewer must adjudicate corpus/utility labels from original source independently of model output and preserve separate stages. If the same model performs both adjudication and insertion decision, report `NONINDEPENDENT`. Any causal actual-answer benefit remains a claim for #101's fresh shared-service gate.

## Required output metrics

Counts with denominators: eligible native events, captured events, source clusters, discovered independent atomic facts, safe source-validated facts, model-established vs provisional vs skip, technical retry, integrity block, duplicates, terminal same-group UUID/index, later retention/promote/supersede/logically retire, falsely skipped useful source-supported facts, operator interventions, model attempts/calls, prompt/completion/reasoning tokens per safely useful retained fact, and observed latency. Preserve the original snapshot and code SHA. Require model request/response raw text to remain private.

## Pass/fail separation

1. `DETERMINISTIC_INTEGRITY`: original-source/privacy/scope/temporal/remote no-replay, retention CAS/rollback, new-evidence-only trigger and source-qualified retrieval exclusion.
2. `MODEL_UTILITY`: actual local model makes useful per-fact decisions on a predeclared set, preserves independent safe facts, does not create routine portal dependence. Report false negatives/duplicates, not invented universal performance.
3. `EX_REMOTE`: Hermes itself need not exit if it is not a classified excluded harness. The installed gate must still prove classified-harness absence, protected inference idleness, quiet grace, no unresolved work and shared EX lock. Require positive terminal Graphiti UUID and index; bounded unknown outcome stays unresolved and is never re-submitted.
4. `ACTIVATION`: not part of premerge trial. Requires reviewed head, trusted Verify, merge/main Verify, reversible source+config promotion and genuinely fresh service/client native session.
5. `RECALL_ANSWER`: #101 final integrated consumer owner; B5 provides source/retention mapping and preliminary readback, not unverified answer-level claims.

A missing or flaky small-n model judgment is not an automatic reason to invent additional safety gates or open a speculative optimization campaign. Correct concrete source/integrity bugs; measure model quality separately.
